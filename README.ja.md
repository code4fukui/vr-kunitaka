# vr-kunitaka

### VR交差点体験 (VR Intersection Experience)

福井県武生市にある2つの実際の交差点をLiDARスキャンデータとA-Frameを用いて構築した、ウェブベースのVR体験コンテンツです。

## デモ

ブラウザ上で交差点を実際に体験できます:

👉 **https://github.com/code4fukui/vr-kunitaka

デモには探索可能な2つのシーンが用意されています:
- **武生高校前交差点 (`cross1.html`):** スキャンされた環境を自由に探索できる静的なシーン。
- **S字交差点 (`cross2.html`):** 走り続ける車が配置された動的なシーン。

## 特徴
- **2つのリアルな環境:** LiDARでスキャンされた実際の交差点の3Dモデル。
- **インタラクティブなWebXR体験:** [A-Frame](https://aframe.io/) を使用して構築された、ブラウザで体験できるVRおよび3Dビュー。
- **VR対応の操作:** VRヘッドセットを使用し、テレポート移動でシーン内を探索可能。
- **クロスプラットフォーム対応の3Dモデル:** アセットは `.glb` (glTF) および `.usdz` 形式で提供されており、様々な3DやARアプリケーションで利用可能。

## 使い方

### デモの体験方法
WebXR対応ブラウザで[デモリンク](https://code4fukui.github.io/vr-kunitaka/)を開きます。デスクトップ環境ではマウスとキーボード（WASDキー）を使って探索でき、対応するヘッドセットを使用すればVRモードで体験できます。

### 3Dアセットの利用
3Dモデルはリポジトリのルートディレクトリに配置されています。ダウンロードしてご自身のプロジェクトにインポートして利用できます。
- **交差点:** `kunitaka-cross1-lidar.glb`, `kunitaka-cross2-lidar.glb`
- **車:** `car-edit.glb`
